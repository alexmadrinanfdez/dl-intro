# DL intro

An introduction to deep learning, presented as a hands-on Jupyter notebook.

## Contents

The notebook introduces neural-network fundamentals, then explains and builds simple examples with different types of neural networks. Examples use TensorFlow and Keras.

- Deep-learning, neural networks, and optimization.
- Feed-forward neural networks.
- Convolutional neural networks.
- Recurrent neural networks and LSTMs.
- Model training and evaluation.

### Repository structure

- [`dl-intro.ipynb`](dl-intro.ipynb) — explanations, code examples, and references.
- [`img/`](img/) — diagrams used in the notebook.

### Reproducibility

The notebook sets a random seed, but results may still vary across library versions, software, and hardware.

## Quickstart

Text and code live together in an interactive (Jupyter) notebook. You have different options to access the notebook.

### Google Colab

[Google Colaboratory](https://colab.research.google.com/notebooks/intro.ipynb) is a hosted environment for python notebooks.
[Open the notebook in Colab](https://colab.research.google.com/github/alexmadrinanfdez/dl-intro/blob/main/dl-intro.ipynb) to run it without installing dependencies locally.

### GitHub

[View the rendered notebook on GitHub](dl-intro.ipynb) to read its explanations, code, and saved outputs without setting up a Python environment. Cells cannot be run from GitHub.

### Local installation

To run the notebook locally, Python and its dependencies need to be installed. Note there is no requirements file at this moment.
Then launch JupyterLab and open the notebook:

```bash
jupyter notebook dl-intro.ipynb
```
